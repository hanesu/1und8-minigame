# 1und8-prototype
An interactive map minigame using maptiler.
map.js generates route of tram, stations and POIs based on corresponding GeoJSON files. 
## Usage
Important: route is currently generated based on stations.geojson, so if you want more points on the route via a separate geojson make sure the coords of stations are part of it  
Images for persons and POIs are to be named "Tom.png", "Jeff.png" etc. and placed in the img folder.
